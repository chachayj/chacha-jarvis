## B. 배송 기다리는 동안 — 코드 (차 없이 가능)

⭐ **작업량이 가장 많은 구간인데 차량이 전혀 필요 없다.** 배송 대기와 겹치게 해라.

### 파이만 있으면 되는 것

- [ ] 1. 파이에 mosquitto 설치
- [ ] 2. 개발PC EMQX ↔ 파이 브로커 **브리지 설정** ← **우선순위 1번**
- [ ] 3. `mosquitto_pub` / `sub` 로 브리지 왕복 검증
- [ ] 4. `robot_id` 배정 (LED 가 `1` 이므로 겹치지 않게)

> 왜 파이에 브로커를 또 두는가 → [08 §7-1](08-rccar-esp32.md#7-1--브로커-위치--파이에-둔다)
> 요약: 현재 EMQX 는 개발PC 에 있고 **ESP32 는 거기 붙을 방법이 없다**(Tailscale 미지원).

### ESP32 보드만 도착하면 되는 것 (모터·차체 불필요)

- [ ] 5. PlatformIO 셋업 + `embeded/esp32/` 폴더 생성
- [ ] 6. 펌웨어 — LEDC PWM 20kHz, **부팅 기본 상태 = 정지**, 워치독(300ms)
      → 핀 배정은 [08 §8](08-rccar-esp32.md#8-esp32-c3-핀-선택). **C3 는 클래식 ESP32 와 핀 제약이 다르다**
- [ ] 7. ⚠️ **관문 3** — MQTT 붙이고, **모터 대신 내장 LED(`GPIO 8`)** 로 검증
      → **브로커를 끄면 LED 가 꺼지는지.** 모터 없이 워치독을 완전히 검증할 수 있다

> 🔴 모터를 붙인 상태에서 워치독을 처음 시험하지 않는다. LED 로 먼저 통과시켜 두면
> 나중에 차가 안 멈춰도 원인이 배선·드라이버로 좁혀진다.

## C. 키트 오면 — 조립과 실측

- [ ] 1. **매뉴얼대로 순정 조립** (Step 1~22). 개조 생각은 하지 않는다
- [ ] 2. ⚠️ **관문 1** — 리모컨으로 주행 확인. **통과 못 하면 여기서 멈춘다**
- [ ] 3. Step 17 조립할 때 **`47+48` / `50` 중 어느 것이 앞으로 갔는지 사진**
      → 다 조립한 뒤엔 안 보인다
- [ ] 4. 플러그 4개(구동모터·조향모터·헤드라이트·배터리)를 **자 눈금 옆에 놓고 사진**
      → 찍는 방법과 피치 계산법: [08 §14-1](08-rccar-esp32.md#14-1-커넥터-사진--무엇을-왜-어떻게-찍나)
- [ ] 5. 나머지 실측 3개 → [08 §14-2](08-rccar-esp32.md#14-2-미확정-5개--확인-절차)

  - [ ] 헤드라이트 리본 **전선 개수**
  - [ ] 배터리베이(`54`) **가로 × 세로 × 깊이** + USB 접근 방향
- [ ] 6. **하네스 주문** → [08 §14-3 결정 트리](08-rccar-esp32.md#14-3-하네스-주문--결정-트리)

## D. 하네스 오면 — 책상 테스트

### ⚠️ "책상에서"의 의미

C-1 에서 차를 완전히 조립했으므로 **모터는 이미 차 안에 있다.** 빼내는 게 아니다.

| | |
| --- | --- |
| 차 | 조립된 상태 그대로. 보드 `49` 에서 **모터 커넥터만 뽑아** 밖으로 빼낸다 |
| ESP32·DRV8833·빵판 | 차 **밖** 책상에 |
| 🔴 차 자세 | **컵·책 위에 올려 바퀴를 공중에 띄운다.** 바닥에 놓으면 그대로 굴러간다 |

- [ ] 1. 보드 `49` **탈거** — 커넥터에서 뽑기만. **보관한다(폐기 금지)**
- [ ] 2. 빵판에 배선 + 콘덴서 3종 → [08 §14-4 배선도](08-rccar-esp32.md#14-4-책상에서-배선--실제-배선도)
- [ ] 3. ⚠️ **관문 2** — PWM **30%** 로 모터 회전 확인
  - [ ] 모터 안 붙이고 전원만 → ESP32 부팅되나
  - [ ] 구동 모터 1개만 → 도나
  - [ ] 조향 모터 추가

> 🔴 **두 가지만 기억하면 된다** (초보 실패의 대부분)
> 1. **GND 공통 연결** — 전원을 둘로 나눴으니 두 GND 를 서로 연결. 안 하면 아무것도 안 돈다
> 2. **470µF 전해 콘덴서는 극성이 있다** — 거꾸로 꽂으면 터진다 (긴 다리 = `+`)

## E. 차에 넣기

- [ ] 1. **배터리베이(`54`)에 ESP32+DRV8833 수납**, AA 3개는 그대로 모터 전원으로
      **USB 포트를 `C28` 커버 쪽으로** → 차 안 뜯고 펌웨어 업로드 가능
- [ ] 2. **AA 팩을 ESP32 `5V` 핀에 공용으로 물린다** ← 먼저 이걸 시도 (추가 지출 0원)
  - [ ] 모터가 움직일 때 **ESP32 가 리셋되지 않는지** 확인
        (증상: 시리얼에 부팅 로그 반복 / 차가 찔끔 가다 멈춤)
  - [ ] 리셋되면 → **470µF 캡을 ESP32 `5V`↔`GND` 에 추가** (콘덴서는 이미 있다)
  - [ ] 그래도 리셋되면 → **그때** [리포 + TP4056](08-rccar-esp32.md#5-4-주문-목록) 주문
  - [ ] ⚠️ 공용으로 갈 거면 **알칼라인**을 쓴다. NiMH(3.6V)는 여유가 없다
- [ ] 3. 순정 리모컨·보드 `49` 를 **차에서 빼서 보관** (2.4GHz 간섭)
- [ ] 4. **관문 3 재확인** — 모터 연결 상태에서 브로커를 끄고 바퀴가 멈추는지.
      **바닥에 내려놓기 전에** 한다
- [ ] 5. 실주행
- [ ] 6. 헤드라이트 → ESP32 GPIO + 220Ω
- [ ] 7. 챗봇 **"불 켜줘" → 차량 헤드라이트** 점등 확인
- [ ] 8. (선택) 텔레메트리 `/Robot_Status` → Cesium 표시

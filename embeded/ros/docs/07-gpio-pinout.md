# 07. GPIO 핀맵과 방향 기준

> 정리일: 2026-09-06 / 출처: 파이에서 `pinout` 직접 실행 + BCM2711 데이터시트 대조

## 1. ⚠️ 가장 먼저 — 헤더 방향을 확정하라

**초보자가 가장 크게 헤매는 지점이다.** 헤더를 180° 뒤집어 보면 핀 번호가 전부 어긋난다.
실제로 이 프로젝트에서도 팬 배선을 "39·35번"으로 오독했다가 실제로는 "2·6번"이었다.

### 뒤집어 읽으면 이렇게 어긋난다

헤더는 **20칸 × 2줄**이다. 180° 돌리면 **칸 순서가 뒤집히고 줄도 서로 바뀐다.**

| 뒤집어 읽은 번호 | 실제 핀 |
| --- | --- |
| 39 | **2** |
| 35 | **6** |
| 40 | **1** |
| 11 | **30** |

> 계산식: 뒤집힌 상태의 `칸 c, 홀수줄` = 실제 `칸 (21-c), 짝수줄`

### 방향을 확정하는 3가지 방법

1. **팬 커넥터 위치** ← 이 파이에서 가장 쉬움
   팬 전선이 꽂힌 쪽이 **1·2번 끝**이다. (빨강=2번 5V, 검정=6번 GND)
2. **기판 뒷면의 사각형 패드**
   1번 핀만 사각형이고 나머지는 전부 원형이다. 가장 확실한 방법.
3. **핀 성격으로 판별**
   1·2번 쪽 끝은 `3V3`/`5V`, 39·40번 쪽 끝은 `GND`/`GPIO21` 이다.

## 2. 전체 핀맵 (Raspberry Pi 4B rev 1.5)

공식 데이터시트 그림: [GPIO, GND 시트.png](GPIO,%20GND%20%EC%8B%9C%ED%8A%B8.png)
아래 표는 파이에서 `pinout` 을 실행해 뽑은 값이며 데이터시트와 일치함을 확인했다.


```
        [팬 쪽 끝 = 1·2번]
             ↓
   3V3  (1) (2)  5V        <- 팬 빨강
 GPIO2  (3) (4)  5V
 GPIO3  (5) (6)  GND       <- 팬 검정
 GPIO4  (7) (8)  GPIO14
   GND  (9) (10) GPIO15    <- ★ LED 접지로 사용
GPIO17 (11) (12) GPIO18    <- ★ LED 신호로 사용
GPIO27 (13) (14) GND
GPIO22 (15) (16) GPIO23
   3V3 (17) (18) GPIO24
GPIO10 (19) (20) GND
 GPIO9 (21) (22) GPIO25
GPIO11 (23) (24) GPIO8
   GND (25) (26) GPIO7
 GPIO0 (27) (28) GPIO1     <- ID_SD/ID_SC (HAT EEPROM 전용, 쓰지 말 것)
 GPIO5 (29) (30) GND
 GPIO6 (31) (32) GPIO12
GPIO13 (33) (34) GND
GPIO19 (35) (36) GPIO16
GPIO26 (37) (38) GPIO20
   GND (39) (40) GPIO21
             ↑
        [반대쪽 끝 = 39·40번]
```

- **홀수 핀**(1,3,5…39)이 한 줄, **짝수 핀**(2,4,6…40)이 다른 줄
- **GND 는 8개**: 6, 9, 14, 20, 25, 30, 34, 39 — 자리가 없으면 다른 데 쓰면 된다
- **27·28번(ID_SD/ID_SC)은 HAT 인식용 예약 핀**이다. 일반 용도로 쓰지 않는다

## 3. BCM 번호 ≠ 물리 핀 번호

**코드에 쓰는 번호와 실제로 꽂는 자리는 다른 체계다.** 가장 흔한 실수다.

| 코드 (BCM) | 물리 핀 |
| --- | --- |
| `GPIO17` | **11번** |
| `GPIO21` | **40번** |
| `GPIO19` | 35번 |

`GPIO21` 이라고 21번 핀에 꽂으면 안 된다 — **21번 핀은 GPIO9** 다.

`gpiozero` 와 `RPi.GPIO`(BCM 모드)는 **BCM 번호**를 쓴다.

## 4. 현재 점유 상황 (실측)

| 핀 | 상태 |
| --- | --- |
| 2번 (5V), 6번 (GND) | **팬 사용 중** — 건드리지 말 것 |
| 그 외 전체 GPIO | `INPUT / pull=DOWN` 기본 상태 = **비어 있음** |

확인 명령:

```bash
raspi-gpio get          # 전 핀 상태
raspi-gpio get 17,21    # 특정 핀만
pinout                  # 보드 정보 + 핀맵 그림
```

> `func=INPUT` 이면 아무도 안 쓰는 상태다. `func=OUTPUT` 이면 뭔가 잡고 있다.

## 6. 이 프로젝트에서 쓰는 핀

| 용도 | BCM | 물리 핀 | 비고 |
| --- | --- | --- | --- |
| LED 신호 | `GPIO17` | **11번** | 팬 쪽 끝에서 가까워 세기 쉽다 |
| LED 접지 | — | **9번** | |

**세는 법**: 팬이 꽂힌 줄의 **반대쪽 줄**에서, 팬 쪽 끝부터 **5번째가 9번(GND), 6번째가 11번(GPIO17)**.

```
GPIO17(11번) -> 저항 220~330옴 -> LED 긴다리(+)
LED 짧은다리(-) -> GND(9번)
```

```bash
cd embeded/rpi
./sync.sh mqtt/led_mqtt.py --broker 100.78.253.44 --pin 17
```

## 7. 안전 수칙

| 항목 | 내용 |
| --- | --- |
| GPIO 전류 | 핀당 **16mA**, 전체 합 50mA. 팬·모터를 GPIO 에 직결하지 말 것 |
| 전압 | GPIO 는 **3.3V**. 5V 를 입력하면 손상된다 (HC-SR04 주의) |
| 팬 전원 | 반드시 **5V(2·4번) 또는 3.3V(1·17번)** 에 연결. GPIO 핀 금지 |
| 배선 시점 | 항상 `sudo poweroff` 후 어댑터 분리하고 작업 |
